🔍 Chrome Extension 連線問題診斷

問題描述

Extension 與 relay server 出現無限連線/斷線循環，server 端收到大量重複連接請求。

步驟 1: 檢查 Service Worker 實例

  1. 開啟新分頁，進入: chrome://serviceworker-internals/
  2. 在頁面內按 Ctrl+F (Mac: Cmd+F) 搜尋 dev-browser 或 3002
  3. 檢查是否有多個 service worker 在運行
  4. 記錄下所有相關的 service worker 數量
⚠️ 如果發現多個實例：
  1. 點擊每個 service worker 旁的 Unregister 按鈕
  2. 等待所有實例都被移除
  3. 繼續執行步驟 2

步驟 2: 完全重置 Extension

  1. 開啟新分頁，進入: chrome://extensions/
  2. 找到 dev-browser extension
  3. 點擊 移除 按鈕，完全移除 extension
  4. 關閉所有 Chrome 視窗
  5. 重新開啟 Chrome

步驟 3: 重新載入 Extension

  1. 進入: chrome://extensions/
  2. 開啟右上角的 開發人員模式
  3. 點擊 載入未封裝項目
  4. 選擇資料夾: /Users/chenshengyang/Documents/aileron/chrome-extension/.output/chrome-mv3
  5. 確認只載入一次

步驟 4: 驗證連線

  1. 點擊 extension icon 開啟 popup
  2. 確認顯示「已停用」+ 灰色圓點
  3. 點擊 toggle 啟用
  4. 應該看到「已啟用」+ 橘色閃爍圓點（連線中）
  5. 幾秒後變成綠色圓點（已連線）
  6. 不應該再出現頻繁的斷線/重連

步驟 5: 查看 Service Worker 控制台

  1. 在 chrome://extensions/ 找到 dev-browser
  2. 點擊 service worker 連結（藍色文字）
  3. 查看 Console 輸出，應該只看到：
    [background] Extension initializing at 2026-01-25T... ConnectionManager created with client ID: ext-xxxxxxxxx-xxxxx
  4. 確認 client ID 只有一個，且不會重複出現

步驟 6: 檢查 Server 日誌

在 terminal 執行：

docker logs workspace-runtime-1 --tail 50 -f

應該只看到：

[conn-xxxxxxx] Extension WebSocket connection initiated [conn-xxxxxxx] Accepting WebSocket... [conn-xxxxxxx] WebSocket accepted, registering extension... [relay] Extension connected (ws id: xxxxxxxxx)

不應該看到重複的連線或 "Extension Replaced" 訊息

⚠️ 如果問題持續

請執行以下檢查並回報結果：

  1. 確認 Chrome 版本 (chrome://version/)
  2. 檢查是否有其他 extension 或防毒軟體干擾 WebSocket 連線
  3. 嘗試在無痕模式下測試（記得允許 extension 在無痕模式運行）
  4. 提供 service worker console 的完整輸出

📋 檢查清單

完成後請確認：

  • ✓ 只有一個 service worker 在運行
  • ✓ Extension 已完全移除並重新載入
  • ✓ Client ID 只有一個且不重複
  • ✓ 連線穩定，無 "Extension Replaced" 錯誤
  • ✓ Server 日誌正常，無大量重複連線
