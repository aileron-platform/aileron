🔍 Chrome Extension Connection Issue Diagnostics

Problem Description

Extension experiences infinite connect/disconnect loop with relay server; server receives numerous repeated connection requests.

Step 1: Check Service Worker Instances

  1. Open new tab and navigate to: chrome://serviceworker-internals/
  2. Press Ctrl+F (Mac: Cmd+F) to search for dev-browser or 3002
  3. Check if there are multiple service workers running
  4. Record the count of all related service workers
⚠️ If multiple instances are found:
  1. Click the Unregister button next to each service worker
  2. Wait for all instances to be removed
  3. Proceed to Step 2

Step 2: Completely Reset Extension

  1. Open new tab and navigate to: chrome://extensions/
  2. Locate the dev-browser extension
  3. Click the Remove button to completely remove the extension
  4. Close all Chrome windows
  5. Restart Chrome

Step 3: Reload Extension

  1. Navigate to: chrome://extensions/
  2. Enable Developer mode in the top-right corner
  3. Click Load unpacked
  4. Select folder: /Users/chenshengyang/Documents/aileron/chrome-extension/.output/chrome-mv3
  5. Confirm it loads only once

Step 4: Verify Connection

  1. Click extension icon to open popup
  2. Confirm it shows "Disabled" + gray dot
  3. Click toggle to enable
  4. Should see "Enabled" + orange blinking dot (connecting)
  5. After a few seconds, changes to green dot (connected)
  6. Should NOT see frequent disconnect/reconnect cycles

Step 5: Check Service Worker Console

  1. Locate dev-browser in chrome://extensions/
  2. Click the service worker link (blue text)
  3. Check Console output, should only see:
    [background] Extension initializing at 2026-01-25T... ConnectionManager created with client ID: ext-xxxxxxxxx-xxxxx
  4. Confirm there is only one client ID and it does not repeat

Step 6: Check Server Logs

Run in terminal:

docker logs workspace-runtime-1 --tail 50 -f

Should only see:

[conn-xxxxxxx] Extension WebSocket connection initiated [conn-xxxxxxx] Accepting WebSocket... [conn-xxxxxxx] WebSocket accepted, registering extension... [relay] Extension connected (ws id: xxxxxxxxx)

Should NOT see repeated connections or "Extension Replaced" messages

⚠️ If Problem Persists

Please perform the following checks and report results:

  1. Verify Chrome version (chrome://version/)
  2. Check if other extensions or antivirus software are interfering with WebSocket connection
  3. Try testing in incognito mode (remember to allow extension to run in incognito)
  4. Provide complete output from service worker console

📋 Checklist

After completion, please confirm:

  • ✓ Only one service worker is running
  • ✓ Extension has been completely removed and reloaded
  • ✓ Client ID is singular and not repeating
  • ✓ Connection is stable, no "Extension Replaced" errors
  • ✓ Server logs are normal, no massive repeated connections
