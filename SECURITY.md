## Reporting a Vulnerability

If you discover a security vulnerability, please do **NOT** report it by creating a public GitHub issue. 

Instead, please responsibly disclose it by sending an email to: **[@test.com]**

### What to include in your report
To help us quickly address the issue, please provide as much information as possible:
* The type of vulnerability (e.g., XSS, SQL injection, RCE).
* Detailed steps to reproduce the issue.
* The expected behavior vs. the actual behavior.
* Any potential impact or risk assessment.

### Response Timeline
* You should receive a confirmation of receipt from our team within **[48 hours]**.
* We will investigate the issue and keep you updated on the progress of the fix.
* Once the issue is resolved, we will coordinate with you on a timeline for public disclosure.
