PPT 風格預覽

這個頁面用於展示本輪候選風格。每套候選預設包含一張首頁、一張目錄頁和一張內容頁，便於使用者快速比較第一印象、結構能力和內容承載能力。

使用方式
先展開候選方案，再點選圖片放大檢視細節。
比較方式
候選數量由當前輪次決定；保持同樣的三種預覽頁型，方便並排比較。
首頁：看氣質 目錄頁：看結構 內容頁：看可用性 卡片：看提案理由

封面頁方向
封面採用較剋制的構圖方式，以簡潔主視覺或抽象科技元素建立第一印象，整體偏穩重、清晰、專業。
內容頁視覺語法
內容頁偏模組化與結構化組織，統一感來自剋制的容器語言、穩定的標題層級和有限的重點強調，不依賴固定版式。
適用場景
正式彙報、產品方案、企業答辯、偏理性的展示場景。
風險點
整體更穩，安全感強，但視覺記憶點可能不如更大膽的方案突出。
首頁
建立第一印象，重點看構圖、主視覺和整體氣質。
目錄頁
檢查這套風格是否能支撐結構型頁面，而不只是好看。
內容頁
檢查資訊進去以後是否清楚、穩、可讀。
